# Internet Cafe Network Design

A graduation project focused on the design, configuration, and documentation
of a small business network using Cisco Packet Tracer.

## Project Overview

The project covers the design and implementation of a small business network,
including network topology, IP addressing, VLAN segmentation, device
configuration, SSH management, and DNS services.

## Technologies

- Cisco Packet Tracer
- Inter-VLAN Routing
- IPv4
- SSH
- DNS
- Static Routing
- OSPF
- NAT
- GRE Tunneling
- RSTP
- Port Security
- Syslog
- FTP
- NTP
- WLAN
- DHCP
- EtherChannel
- HSRP
- IoT
